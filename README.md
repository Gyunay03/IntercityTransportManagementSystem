## English

# IntercityTransportManagementSystem

A comprehensive web application designed to automete intercity transport scheduling, bus seat allocation, and ticket management.

### Project Evolution:
  * **Current Status:** Being evolved into my final **Bachelor's Diploma Project**.
  * **Origin:** Started as a specialized academic course project.

### Technical Scope:
  * **Full-cycle Development:** From system analysis and database design to implementation.
  * **Back-end Logic:** Focused on data integrity and system reliability.
  * **Database:** Efficient schema design using SQL Server.

### Technologies:
  * **Framework:** ASP.NET MVC
  * **Language:** C#
  * **Database:** Microsoft SQL Server Management Studio

# Система за управление на междуградски транспорт

Комплексно уел приложение за автоматизиране на графици за междуградски транспорт, управление на места в автобусите и продажба на билети.

  * **Произход:** Започнат като специализиран проект по дисциплината "Курсов проект".

### Технически обхват: 
  * **Пълен цикъл:** От системен анализ и проектиране на база данни до реализация.
